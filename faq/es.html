1. ¿Qué huso horario se utiliza como referencia en las fechas y la información horaria proporcionadas, como en el caso de los intercambios de Pokémon?
En la Pokémon GTS se utiliza siempre la hora del meridiano de Greenwich (hora GMT).
2. ¿Cuándo se actualiza la información?
Los datos se actualizan a diario, sobre la 01:30 de la mañana (hora GMT), con la información recopilada el día anterior.

REQUISITOS MÍNIMOS DEL SISTEMA:

1. Explorador de internet:
La Pokémon GTS funciona correctamente con los siguientes exploradores (si no utilizas uno de los siguientes exploradores, es posible que el sitio no se pueda ver):
Windows Internet Explorer 6.0 SP2 y superior
Macintosh Safari 1.3 y superior
Firefox 2.0 y superior
Opera 9.2 y superior

2. JavaScript, StyleSheet (CSS)
Todas las páginas de la Pokémon GTS utilizan JavaScript o StyleSheet (CSS). Configura tu explorador de tal forma que pueda utilizar JavaScript y StyleSheet (CSS).

3. Plug-in
Se necesita el siguiente plug-in para ver la Pokémon GTS:
Macromedia® Flash™ Player 9,0,45,0 o posterior
* Es necesario tener derechos de administrador para actualizar el reproductor Flash Player. Si eres menor de edad, consulta con tus padres o tu tutor antes de realizar la actualización.
5. ¿Se puede acceder al sitio web con la consola Wii?
Lo sentimos, este sitio no se puede ver con la consola Wii.
6. El mensaje "Instalar Flash Player" sigue apareciendo después de instalar el programa.
Este mensaje se muestra porque no se ha completado la instalación de Flash Player en tu PC. Es posible que debas reiniciar tu ordenador. Puede que tu software de seguridad haya impedido la instalación o que tu PC no cumpla los requisitos mínimos. Para saber cuáles son los requisitos mínimos, consulta la sección anterior.
